# Best from each — mixed into M4ster Pro

Competitive teardown (Oct 2026): Linear, Asana, Monday, ClickUp.
What each does best, and what becomes a Pro feature here.

## From Linear — speed + dev workflow

- **Triage inbox** — new issues land in an inbox; keyboard-driven accept,
  route, or snooze. The single best dev-workflow idea in the market.
  → **Pro view: Triage** (build first)
- **Cycles** — auto-scheduling sprints. We have Sprints; add Linear-style
  auto-cycle config → Pro
- **Slack intake** — turn a Slack message into an issue ("Asks").
  → Pro integration
- **Git auto-close** — commit message closes the issue. → Pro dev integration
- **Command menu depth** — we have Cmd+K; keep deepening it (free)

## From Asana — strategy + structure

- **Goals** — company objectives with progress rolling up from epics/issues.
  The "strategy → execution" story nobody at our price has.
  → **Pro: Goals** (build second)
- **Portfolios** — multi-project dashboard. → Pro (pairs with unlimited projects)
- **Forms intake** — shareable form feeds issues into Triage. → Pro
- **Dependencies + critical path** — on our Timeline view. → Pro
- **Rules/automations** — validates our automations engine as Pro. Already have it.

## From Monday — trial + presentation

- **14-day Pro trial mechanics** — formalize what our demo unlock does:
  timed trial, graceful downgrade. → Phase 3 with Stripe
- **Dashboards** — customizable widgets (extends Reports). → Pro

## From ClickUp — generosity + trust

- **Native time tracking** — we have time entries; surface it Pro with reports.
- **Custom statuses** — beyond fixed columns. → Pro
- **100% money-back guarantee** — not a feature, a policy. Goes on the
  landing page. Costs nothing, buys trust.

## The Pro mix — build order

1. **Triage inbox** (Linear's best idea; nobody at $20/yr has it)
2. **Goals** (Asana's best idea; the pitch writes itself)
3. **Forms intake** (feeds Triage; teams love it)
4. **Dependencies + critical path** (makes Timeline Pro-grade)
5. **Dashboards** (Monday/ClickUp parity, customizable)
6. **Slack intake + Git auto-close** (dev integrations)
7. **Custom statuses** (ClickUp parity)

## What we deliberately DON'T copy

- Seat buckets, ghost seats, per-seat math — the whole point is we don't.
- SSO behind "Contact Sales" — with flat pricing, SSO is for everyone (later).
- Everything-bloat (ClickUp's kitchen sink) — fast core stays fast.
- Automation overage meters — unlimited means unlimited.
